# Swayam Harawade — Portfolio

Editorial multi-page portfolio: Home, Experience, Services, Projects, Skills, Contact.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Deploy on Vercel (recommended)

1. Unzip this folder and push it to GitHub, or import the folder in Vercel.
2. Build command: `npm run build`
3. Deploy.

## Deploy on Netlify

Vercel is the intended host. For Netlify, change `preset: "vercel"` in `vite.config.ts` to `preset: "netlify"` first.
